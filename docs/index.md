## 实践体会

我是7uuu-uuu，通过这次实践，我亲手体验了“编写 Markdown 源码 -> GitHub Actions 自动构建 -> GitHub Pages 托管发布”的完整流程。最大的感受是自动化带来的便利，只要把代码 `push` 到仓库，剩下的工作全部交由云端服务器完成，无需再把文件传到服务器上。这让我对现代软件工程中的 持续集成与持续部署概念有了更直观的认识。
