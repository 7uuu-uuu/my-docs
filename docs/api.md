以下接口仅用于文档展示，不提供真实服务。

## 查询文档列表

- 请求方法：GET
- 请求路径：/api/docs
- 功能：返回文档条目列表。

### 请求参数

| 参数名 | 类型 | 是否必填 | 描述 |
| --- | --- | --- | --- |
| page | Int | 否 | 页码，默认为 1 |
| size | Int | 否 | 每页数量，默认为 10 |


### 返回示例

这里展示一段 JSON 格式的代码：

```json
{
  "code": 200,
  "message": "success",
  "items": [
    {
      "id": 1,

  ]
}
